# 🧭 우리 동네 안심 효도 지도 (반응형 웹앱)

시니어 어르신들이 스마트폰과 PC에서 자주 가는 단골 병원, 약국, 공원, 복지관 등을 **왕방울만 한 버튼**으로 콕 눌러 한 번에 길을 찾고 전화도 걸 수 있는 효도 웹앱입니다.

---

## 🔑 카카오 키 탑재 완료
* **등록된 카카오 JavaScript 키**: `55148ba167bb060d42de019ce8797b3b`
* 코드가 자동으로 이 키를 읽어 실시간 카카오 지도를 띄워줍니다!

---

## 🚀 가장 쉬운 실행 방법 (클릭 한 번!)

1. `c:\sb_file\kakaomcp` 폴더에서 **`실행하기.bat`** 파일을 마우스로 **더블 클릭**하세요!
2. 검은 창이 뜨면서 인터넷 브라우저가 자동으로 열리고, `http://localhost:3000` 주소로 지도가 짠! 나타납니다.

---

## ⚠️ 카카오 개발자 센터 도메인 등록 1초 체크!
카카오 지도가 화면에 정상적으로 나타나려면 카카오 디벨로퍼스에 우리 집 주소(도메인)를 알려주어야 합니다.

1. 카카오 디벨로퍼스 접속: [https://developers.kakao.com/console/app/1644514/config/platform-key](https://developers.kakao.com/console/app/1644514/config/platform-key)
2. 왼쪽 메뉴 **[앱 설정] > [플랫폼]** 클릭
3. **[Web 플랫폼 등록]** (또는 수정)을 누르고 **사이트 도메인**에 아래 주소를 입력 후 저장:
   ```text
   http://localhost:3000
   ```
*(이 주소가 등록되어 있어야 카카오에서 지도를 안전하게 보여줍니다!)*

---

## 🌟 주요 기능
1. **왕방울 장소 버튼**: 큰 병원, 행복 약국, 산책 공원, 경로 복지관, 하나로마트
2. **원터치 길안내**: 카카오맵 도보/차량 길안내 바로가기
3. **원터치 전화걸기**: 병원이나 단골 매장에 바로 전화 연결
4. **내 위치(GPS) 찾기**: 길을 잃었을 때 현재 위치 깃발 꽂기
5. **장소 커스텀(수정)**: 오른쪽 위 `[⚙️ 설정]` 버튼으로 언제든 장소/전화번호를 추가하거나 변경 가능
